# Book Tracker

**Автор:** соколова
## Описание программы

Приложение «Book Tracker» — это простой инструмент для ведения списка прочитанных книг. Оно позволяет добавлять новые книги с указанием названия, автора, жанра и количества страниц.
Ключевые функции включают фильтрацию списка по жанру и количеству страниц (например, «показать все книги в жанре 'Фантастика' объемом более 300 страниц»). Все данные надежно сохраняются в локальный файл `books.json`, что позволяет не терять информацию при закрытии программы.
Проект использует систему контроля версий Git для отслеживания изменений в коде.

## Технологии

*   **Python:** Язык программирования.
*   **Tkinter:** Библиотека для создания графического интерфейса (*GUI*).
*   **JSON:** Формат хранения данных.
*   **Git:** Система контроля версий.

## Инструкция по запуску

1.  Установите Python версии 3.x с официального сайта (https://www.python.org/).
2.  Склонируйте этот репозиторий на свой компьютер или скачайте папку с проектом.
3.  Откройте терминал или командную строку.
4.  Перейдите в папку с проектом: `cd путь/к/book_tracker`.
5.  Запустите приложение командой:
    ```bash
    python book_tracker.py
    ```
6.  Откроется окно программы.
